# 全站视觉与文案层级优化方案

## 目标
- 降低页面文字压迫感
- 强化标题、状态、说明、结果之间的视觉层级
- 让页面更像工作台，而不是长篇说明文档
- 在不改变主流程的前提下，提升可扫读性与决策效率

## 设计原则
- 颜色必须表达语义，而不是仅用于装饰
- 先让用户看到“当前状态、下一步、风险点”
- 保留必要说明，压缩重复背景文本
- 表单页强调操作区，结果页强调结论区

## 颜色语义
- 主色：橙色，用于当前阶段、主按钮、关键 CTA
- 成功色：绿色，用于已完成、已具备、通过
- 信息色：蓝青色，用于提示、建议、说明模块
- 警示色：琥珀色，用于待补齐、注意事项、待处理项
- 风险色：红色，用于关键差距、阻塞项、异常项
- 中性色：灰色，用于辅助说明、弱提示、副文本

## 文本层级
- 页面标题：最高层级，承载页面核心目的
- 模块标题：次级层级，帮助快速定位内容区块
- 关键状态：高对比度 + 状态色，优先被看见
- 正文说明：正常对比度，控制长度
- 辅助提示：较低对比度、较小字号

## 布局策略
- 顶部使用 Hero 区承载标题、摘要、主操作
- 中部使用卡片区承载状态、待办、建议
- 表单页使用明显的填写区块和字段提示
- 结果页优先展示结论，再展示解释细节
