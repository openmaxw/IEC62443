# IEC 62443 需求澄清与响应工作台

将模糊安全诉求转化为标准化项目输入与清晰响应路径。

这是一个面向 IEC 62443 项目场景的公开前端工作台原型，用于帮助业主、集成商与设备商围绕同一项目上下文完成需求澄清、设计响应、能力声明、匹配闭环与交付摘要。

## 项目定位

本项目是项目前期需求澄清、响应引导与交付准备工具，不是自动合规判定工具，也不是替代专家判断、正式风险评估、详细设计审查或认证结论的黑盒生成器。

它的目标是把 IEC 62443 项目推进过程中常见的几段关键翻译显式化、结构化：

- 需求澄清 → 风险关注
- 风险关注 → 设计响应
- 设计响应 → 能力声明
- 能力声明 → 匹配闭环与交付摘要

换句话说，它更像一个围绕单一项目对象运行的协同工作台，而不是一组彼此分散的页面。

公开版适合用于说明 IEC 62443 项目前期协同方法、演示多角色信息流转、沉淀可追溯交付草稿；所有规则、映射和建议都应结合具体项目背景与专家评审再确认。

## 当前能力

当前版本已经具备一条可连续推进的主链：

- 需求澄清
- 设计响应
- 能力声明
- 匹配闭环
- 追溯与交付摘要

系统当前支持：

- 项目级状态统一维护
- 多阶段结果连续流转
- 结果页、匹配闭环页、追溯页和交付摘要页联动
- 基于本地规则的风险转译、设计响应建议与匹配分析
- 本地存储下的断点恢复与演示项目加载
- IEC 62443 映射依据查看与 Markdown 交付摘要导出

## 主流程

```text
项目总览
  -> 需求澄清与风险转译
  -> 设计响应与能力需求分配
  -> 能力声明
  -> 匹配分析与差距处置
  -> 追溯查看与交付摘要
```

每一阶段都以“可交接结果”为目标，而不是只停留在表单输入。

## 页面结构

- `/`：首页
- `/dashboard`：项目总览
- `/owner`：需求澄清
- `/owner/result`：项目输入摘要
- `/integrator`：设计响应
- `/integrator/result`：设计响应摘要
- `/vendor`：能力声明
- `/vendor/result`：能力声明摘要
- `/selection`：匹配闭环
- `/translation-center`：项目追溯链
- `/report`：交付摘要
- `/learning`：使用手册

## 技术结构

- `React 19`
- `Vite`
- `React Router`
- `Context + hooks`
- `CSS Modules`

项目当前已逐步形成以下分层：

- `schema`：核心对象正式结构
- `normalize`：状态入口归一化
- `selector / view model`：页面消费契约
- `pages`：任务输入、结果展示与交互流程

## 本地运行

安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

构建：

```bash
npm run build
```

运行最小契约测试：

```bash
npm run test:contract
```

## 当前边界

- 当前仍是前端原型，未接入后端、账户体系或真实设备数据库
- 风险转译、设计响应建议和匹配分析依赖本地规则与模板，不替代正式风险评估
- 输出适合前期协同、方案整理与交付准备，不等同于认证结论
- 演示数据为虚构示例，不代表任何真实企业、地区、产品或认证背书
